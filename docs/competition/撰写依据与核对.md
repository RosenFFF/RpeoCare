# 技术报告撰写依据与核对

报告以AI+开源专用规则和参考大纲确定内容，以本地通用模板的明确文字确定排版。参考大纲说明不要求机械套用，正文建议15页以内，附录按需提供；本报告采用其八个正文部分，另设作品简介和附录。该核对面向参赛者，不替代身份、权属和正式上传确认。

## 文件依据与优先关系

- [官方通知及附件1](https://www.aicomp.cn/notice/notice-3/4890.html)：PDF不超过10MB，第三方清单随报告附上，评审材料不得出现学校名称、学校标识或指导教师信息。
- [附件2 AI+开源技术报告参考大纲](https://www.aicomp.cn/wp-content/uploads/2026/08/%E9%99%84%E4%BB%B62_AIC%C2%B7AI%E5%BC%80%E6%BA%90%E6%8A%80%E6%9C%AF%E6%8A%A5%E5%91%8A%E5%8F%82%E8%80%83%E5%A4%A7%E7%BA%B2260812.pdf)：封面字段、八个正文部分和附录建议。
- 工作区`作品提交要求/2026AIC-算法主题赛-作品方案模板示例.doc`：宋体字号、单倍行距及页面设置。已只读转换核查，源文件未修改。模板内部部分实际格式与文字提示不一致，采用明确文字要求；通用占位章节不覆盖AI+开源专用大纲。

官方附件2已从通知链接保存到工作区`作品提交要求`，与规则PDF和Word模板一起供本地核对。官方文件未复制到本项目公共源码中。

## 排版与交付核对

| 项目 | 采用设置或判据 | 说明 |
| --- | --- | --- |
| 纸型与页边距 | A4纵向，上下2.5厘米，左右3厘米 | 按模板明确文字设置，装订线0 |
| 正文字体 | 宋体，小四12pt，单倍行距 | PDF生成按宋体基线单倍排版，不沿用旧版10.5pt正文 |
| 标题层级 | 一级16pt、二级14pt、三级12pt，加粗 | 目录标题22pt加粗；沿用宋体字形 |
| 页眉页脚 | 各1.5厘米，封面不印页码 | 目录起编号，目录页码与实际章节核对 |
| 表格与图注 | 宋体10.5pt，独立于正文角色 | 模板未单独指定表格字号；保持表格可读，未缩小正文凑页数 |
| 图示与截图 | 两张矢量图、真实页面局部放大 | 不重绘实际UI状态，保留来源哈希与裁切区域 |
| 篇幅与大小 | 正文含简介不超过15页，PDF不超过10MB | 封面、目录及附录另计；以实际生成结果核验 |
| 作品简介 | 不超过300字 | 按问题、方案、效果与应用说明 |
| 资源清单 | 完整CSV内嵌PDF并单独随包交付 | 逐项待核验状态如实保留 |

PDF需逐页渲染查看，核对封面、目录、表头重复、图中文字、正文与页脚留白、字形及截图语义。字体与大小检查、CSV字节校验和图像来源检查作为补充，不能替代目检。

## 参赛者还需补齐的事实

团队名称、编号、成员分工、人工工时和人工审核记录按参赛者要求用xx占位。这些字段未核实前不填写人员经历或完成声明。学校及指导教师信息不进入评审材料。

模型首次交付、反馈后候选、外部每版一次与页面副本每版三次分别记录；不将生成计划当作执行成功，不根据两个历史案例推算准确率或人工省时。真人反馈、上游采用及完整项目测试未完成的范围仍保留。

评审访问授权、共同权属、第三方实际分发义务、连续录屏充分性和平台回执仍需负责人按实际完成。仓库可推送与评审能访问不是同一状态。本报告的结构与排版通过核对，不表示已具备全部提交条件。
