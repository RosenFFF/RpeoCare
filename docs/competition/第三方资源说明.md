# 开源及第三方资源使用清单

本清单与技术报告附录 A 一致。"已核验"表示团队已核对许可类型、使用方式与义务履行情况。RepoCare 只以源码形式开放：npm 依赖由使用者自行安装，仓库不包含 node_modules、构建产物、容器镜像、模型权重或任何密钥。

## 自主开发边界

| 类别 | 内容 |
| --- | --- |
| 第三方开源/受许可部分 | pi Agent SDK 的 Agent 循环与模型协议适配；Next.js、React、SQLite、Docker、pytest 等框架与运行时；模型服务的推理能力；GitHub API 提供的仓库数据 |
| AI 工具辅助部分 | 开发中使用 OpenAI Codex 辅助代码草拟、问题定位、测试与文档整理；使用 Claude Code 辅助整理参赛材料。所有改动经团队审阅与测试后提交 |
| 团队自主设计与实现 | 维护任务状态机与持久队列；18 个维护工具及服务端约束；需求—补丁—测试映射与双版本计划编排；环境预检与计划指纹绑定；结论判读规则；证据编号校验与预算收尾；PR 分块审查与 Diff 坐标校验；体检规则；全部界面与可视化；产品手册、测试与评测协议 |
