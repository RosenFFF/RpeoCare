# 作品名称与简介

## 名称

RepoCare开源维护助手

## 简介

面向中小型开源项目维护者，RepoCare将Issue需求、PR改动与验证证据关联到固定代码版本。系统内嵌pi Agent开展源码调查，通过项目规则、引用校验、共享测试双版本执行和人工确认，辅助判断候选是否改善目标、是否引入回归。人工提供的验收测试独立保存来源声明、内容指纹与执行记录。作品已开展公开仓库历史任务的探索性验证，保留环境阻塞、失败候选和人工介入；不宣称稳定自主修复或维护者采用。代码、部署说明和脱敏实验索引构成开放成果，完整复现材料按许可边界提供。

本简介为审阅稿，效果与开放安排应在最终提交前再次核对。
