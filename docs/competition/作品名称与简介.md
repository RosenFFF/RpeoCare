# 作品名称与简介

## 作品名称

RepoCare：证据驱动的开源维护助手

## 参赛方向

AI开发工具与开源协作

## 作品简介

AI能快速生成补丁，但维护者仍需判断：补丁是否满足Issue要求、是否破坏原有行为、测试失败是缺陷还是环境问题。RepoCare让AI调查源码、提出方案，由执行证据下结论：将Issue原文、固定版本源码、候选补丁与测试绑定，在断网容器中用同一测试对照原版与候选，自动区分目标改进、候选回归与环境受阻，关键步骤由维护者确认。作品基于pi Agent SDK、Next.js与Docker实现，覆盖体检、分诊、PR审查、文档与修复验证。在11个开源项目的真实Issue/PR上实测，发现了候选补丁对正常行为的破坏，两项新任务经一次反馈修订后通过全部冻结检查。源码与评测索引以Apache-2.0开源。
