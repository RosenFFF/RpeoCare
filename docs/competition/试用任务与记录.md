# 首次使用者试用任务与记录

## 准备

邀请 2–3 名未参与开发的同学或开发者。使用演示实例（python-json-pointer #63 的真实任务记录），不共享模型密钥、个人数据库或上游写入权限。开始前只介绍"RepoCare 是帮助开源维护者判断 AI 补丁的工具"，不演示操作。

## 四项任务

1. 在项目概览中找到当前最需要处理的事项，说出下一步该做什么。
2. 打开 Issue #63 的"修复与验证"，说出 AI 提出的补丁改了哪个文件、为了解决什么问题。
3. 查看两版执行结果，说出系统的结论是什么、依据是什么、哪些范围还没有验证。
4. 导出 JSON 证据，并说明拿到这份文件的人可以核对哪些内容。
