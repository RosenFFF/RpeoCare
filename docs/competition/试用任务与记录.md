# 首次使用者任务与记录

## 使用方式

邀请2至3名未参与当前界面开发的使用者，说明其真实角色（同学、开发者或维护者）。不要求其给好评，不把同学走查称为上游维护者采用。使用独立演示账户和公开案例，不共享模型密钥、个人数据库或上游写入权限。

## 四项任务

1. 从概览找到当前最需要处理的事项，并说明下一步。
2. 打开一个Issue，判断缺少哪些信息、哪些分类尚未确认。
3. 打开一个PR的需求对照，说明目标、正常回归及验收来源能支持什么结论。
4. 找到一条受阻记录，说明原因、未执行范围和可采取的恢复动作，再导出结果。

## 记录要求

逐项记录实际开始与结束时间、是否独立完成、求助次数、第一次误解、卡住位置和使用者原话。未完成直接标未完成，不补填耗时或满意度。将任务说明与实际观察分开，修复后再记录复测版本，不覆盖旧记录。得到使用者允许后才保存可识别信息或对外引用原话。

当前没有在本文件预填真实反馈。完成走查后再汇总可核验结果，样本较小时只作探索性可用性观察。
