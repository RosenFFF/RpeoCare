# 本轮实现与验收范围

## 已接入代码

- 真实仓库项目上下文、概览、任务与草稿统计，最近两次报告共有检查项的状态对比。
- 私有 GitHub 仓库与分支选取（私有访问需授权）；固定提交快照。
- 报告固定快照展示；AI Issue 可解释分类、中文翻译、PR patch 审阅草稿。
- PR 证据化审查：固定提交、实际 Diff 行号/片段校验、可见 CI 与关联需求、人工确认与历史、绑定报告版本的评论草稿。详细边界见 PR_REVIEW.md。
- Bug 复现实验室：结构化计划、受限项目测试、Playwright/HTTP 操作、独立队列 Worker、Docker 隔离、3 次稳定性验证与 SHA-256 证据下载。
- 文档维护工作台：从报告生成 README、贡献指南、Issue／PR 模板等 Markdown 草稿；展示文档资产和草稿来源（任务、检查项及证据），支持编辑／预览／Diff 三态、保存、重新生成与下载。
- 文件草稿经明确确认后创建独立分支 Draft PR；工作台不直接修改默认分支，Issue 评论和 PR 审阅仍沿用独立的发布确认流程。
- 写回支持 Issue 评论、PR COMMENT、独立分支草稿 PR；校验草稿版本和远程提交。
- 维护者确认结果与 AI 原始建议分离保存，并保留分诊事件历史。
- PR 证据化审查：固定 head/base、可见 Diff 与 CI/Status、关联 Issue、结构化发现、代码片段校验、人工筛选、历史与版本绑定草稿。
- GitHub OAuth/PKCE、邮箱注册验证登录和重置、登录保护。
- 快照恢复、同机多 Worker、最后一轮 Agent 收尾、调用/token 统计。
- Python/Go/Java 测试文件和多语言规范配置的存在性检查。
- Lint、扩展单元/集成测试、浏览器回归脚本、CI、健康检查、Docker Compose、备份与清理命令。

- Issue / PR 共用全宽收件列表与明确维度筛选，取消双栏空占位和唯一 PR 自动进入，详情返回保留筛选与焦点。

## 验收需要的外部配置

- GitHub OAuth App 的 ID/Secret 与正式回调地址。
- SMTP 与发信地址，验证真实送达。
- 生产域名/服务器、HTTPS 反向代理与来源 IP 限流。
- 真正持有权限的测试仓库，用于私有读取和经确认的发布验收。

- 自动定时清理/备份调度、集中日志告警平台。
- 多仓库切换历史管理、完整跨版本报告 Diff（当前展示任务历史和最近两次共有检查项状态变化）。
- 文档语义完整性、所有命令及外部链接的真实验证仍未覆盖。草稿中心已加入 GFM 预览、真实 Diff 和有界静态校验，不能替代运行测试或全面秘密扫描，详见 DRAFT_WORKSPACE.md。

本轮开发测试不会实际发送验证邮件、消费真实模型额度或发布 GitHub 测试评论。外部环境未配置的能力必须以待验收说明，不可描述为线上已可用。

## 本地验收结果（2026-10-05）

`npm run check` 通过：Lint、类型检查、84 项测试、生产构建。新增 8 项 PR 业务测试，覆盖证据校验、CI 三态、PR 快照变化、人工筛选、版本冲突和草稿发布保护；13 项浏览器回归全部通过，包含统一收件列表、0/1/多条、筛选恢复、错误状态、批量范围、深色和窄屏场景。

在线数据库备份成功；清理命令以 dry-run 验证。Compose 配置保留 Web 与体检 Worker。复现 Worker 推荐运行在独立 Docker Runner 主机。2026-09-30 验证时 Docker CLI 可见但 Docker Desktop 引擎未运行，故已完成 fail-closed 测试和 Runner 语法校验，仍未完成镜像构建与真实沙箱执行验收。上述更大范围仍未完成，本轮成果不等于全部产品路线图完成。
