# 作品名称与简介

## 作品名称

RepoCare 开源维护协作工作台

## 作品简介（300字以内）

开源项目维护者每天需要处理 Issue 分诊、项目体检、PR 审查、Bug 复现和文档维护，但信息分散、上下文不足、AI 建议难核验，导致维护成本高、误判风险大。RepoCare 是面向开源维护者的 AI 协作工作台：连接 GitHub 后，围绕固定代码提交和公开协作材料，提供证据化项目体检、Issue 分诊、PR 审查、受控 Bug 复现与维护文档生成。系统不是把模型输出直接当结论，而是通过结构化输出、文件与 Diff 证据校验、人工确认、任务状态可视化和 Docker 隔离 Runner，将“建议”转化为可追溯、可复核的维护线索。作品已在 encode/httpx、pallets/click 两个真实公开仓库历史材料上完成阶段性对照实验，并在 BackupGuard、SchemaGuard、TaskLite 三个明确标注的合成仓库上进行可控场景验证。核心代码、实验说明、数据卡和部署文档按许可证边界开放，限制和未完成的人工标注也如实披露。
