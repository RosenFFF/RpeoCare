# RepoCare 前端 QA

## 文档维护工作台（本轮功能范围）

- 规范改进页提供文档资产导航，可从最近一次体检报告生成 README、贡献指南和 Issue／PR 模板等 Markdown 草稿。
- 草稿保留来源追溯信息，能够回到生成它的体检任务、检查项和文件证据；旧草稿没有来源字段时仍可编辑。
- 编辑区支持编辑、渲染预览和前后 Diff 三种视图，并提供保存修改、重新生成和下载 Markdown。
- 文件草稿发布前必须显式确认，发布目标为独立分支的 Draft PR；不会自动修改默认分支或自动合并。
- 本轮尚未把 Markdown 链接、命令和渲染安全检查描述为已通过的自动化能力；这些内容仍属于后续增强项，预览与 Diff 只作为人工审阅辅助。
