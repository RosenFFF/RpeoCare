# 术语、状态与限额

本章是速查表：界面上的词汇和状态是什么意思、各项处理有哪些上限、RepoCare 目前能做和不能做什么。

## 常用术语

| 术语 | 含义 |
| --- | --- |
| 快照 / SHA | 固定的 Git 提交版本，让报告和证据可以复查 |
| base / head | PR 的合并目标版本 / 待合并的改动版本 |
| Diff | 相对于基线的文件改动 |
| 证据 | 结论引用的原始内容：文件路径与原文、Diff、CI 检查、执行日志 |
| 关注分 | Issue 已知信号的规则加权和，用于决定查看顺序，不代表严重程度 |
| 线索 | 来自标签或标题的类别提示，只用于导航，不是正式分诊 |
| 分块审查 | 把 PR 的 Diff 按文件和变更段切块，逐块交给模型审查 |
| 机器判据 | 复现计划中“怎样算复现成功”的可自动判断条件 |
| 对照验证 | 用同一组测试分别运行原始版本和候选版本，比较目标行为和回归结果 |
| Worker | 在后台处理队列任务的进程 |
| Runner | 执行已确认计划的 Docker 隔离环境 |
| 草稿 / Draft PR | 尚待审阅的内容 / GitHub 的草稿合并请求，都不表示已合并 |
| COMMENT | 评论型 PR 审阅，不等于批准或请求修改 |

## 通用状态

| 状态 | 含义与操作 |
| --- | --- |
| 排队中 / 等待执行 | 等待 Worker 领取；长时间不动先检查对应 Worker |
| 运行中 / 执行中 | 正在处理，可以离开页面 |
| 完成 | 任务结束；仍需查看结论、覆盖范围和证据 |
| 部分完成 / 未审 | 有失败或未覆盖的内容，不能当作完整结果 |
| 已过期 / 原文已更新 | 来源版本变了，需要按新版本重新处理 |
| 环境受阻 / 环境阻塞 | 执行环境不满足条件，不是对业务行为的判定 |
| 未知 / 无法判断 | 证据不足；不当作通过，也不当作失败 |
| 已取消 / 已停止 | 由维护者停止，已有记录保留 |

## 各模块状态

**项目体检**：已通过、待完善、无法判断。

**Issue 处理状态**：未分诊、待补充信息、准备复现、准备回复、待调查、已回复、人工审阅。

**PR 审查阶段**：待审查、审查进行中、待确认发现、需重新审查、审查完成。

**复现结果**：稳定复现、未稳定复现、环境阻塞、计划不安全、执行失败、已取消。

**贡献路径**：已走通、有阻塞、环境阻塞、计划已阻止、执行失败、已取消。

**草稿**：待审阅、发布中、已交付、待核对、已归档。

## 处理上限

| 项目 | 上限 |
| --- | --- |
| Issue / PR / 仓库列表 | 每页最多 30 条，筛选只作用于当前页 |
| 批量分诊 | 每次最多 12 条 |
| 体检内容研判 | 7 轮、18 次工具调用、90 秒，报告不超过 24,000 字符 |
| 分诊、PR 审查、文档生成 | 每次最多 6 轮、12 次只读工具调用，单次请求 60 秒 |
| 模型输入 / 草稿文本 | 100,000 字符 / 30,000 字符 |
| PR 分块审查 | 单任务最多 32 个可执行块；每块一次调用，至多一次格式修复，最多尝试 3 次 |
| PR 审查任务 | 同时最多 3 个排队或运行；每小时最多创建 30 个 |
| 文件改动片段 | 观察面板中每个文件最多展示 Patch 前 40 行 |
| 草稿历史版本 | 保留最近 20 个 |
| 合并交付 | 一个 Draft PR 最多合并 4 个文件草稿 |
| Bug 复现 | 默认执行 3 次，至少 2 次命中机器判据为稳定复现 |
| 隔离执行时间 | 默认 180 秒，可配置 30–300 秒 |
| 隔离执行资源 | 2 个 CPU、2 GB 内存、256 个进程 |
| 人工验收测试文件 | 最多 20KB |
| 连接测试 | 最多 512 个输出 tokens、25 秒 |
| 模型请求诊断 | 最近 5 条 |

## 功能边界

- **平台**：只支持 GitHub，GitLab 和 Gitee 地址不是受支持的入口。
- **体检**：读取固定快照，不运行被检查仓库的代码。
- **AI 结论**：分诊、审查发现、修复候选和文档建议都需要人工核对。
- **PR 审查航道**：阶段只来自已保存的审查记录；横向位置只表示距上次更新的时间，不代表风险或优先级。
- **隔离执行**：复现只支持公开 GitHub HTTPS 仓库；贡献路径和需求对照只覆盖计划中选定的步骤；对照验证以 Python / pytest 场景为主。
- **发布**：每次发布都需要明确确认；文档改进目前只支持默认分支；不会自动批准或合并 PR。
- **部署**：基于同机共享的 SQLite，不提供开箱即用的跨机器分布式队列。

## 键盘快捷键

| 位置 | 快捷键 | 作用 |
| --- | --- | --- |
| 工作区 | `Ctrl` / `⌘` + `K` | 快速跳转到工作区页面 |
| 工作区 | `Esc` | 关闭弹窗或窄屏导航 |
| Issue 探索画布 | 滚轮 / 拖动 / `0` | 缩放 / 平移 / 恢复全图 |
| 使用手册 | `Ctrl` / `⌘` + `K` 或 `/` | 打开全文搜索 |
| 使用手册搜索 | `↑` `↓` / `Enter` / `Esc` | 选择结果 / 打开 / 关闭 |
